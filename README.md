# 焰火声光核查台

用观众席上**一部手机录下的视频**，核查音乐焰火晚会上每一朵礼花是否在音乐重拍上炸开，并反推编排表的点火时间修正量。

## 解决的问题

礼花弹从点火到开花要飞行数秒，口径不同飞行时间不同；观众听到的爆炸声又比看到开花晚（声速传播）。导演只能凭感觉判断、回放手机录像也看不准。本工具把这件事变成可量化的毫秒级核查：

1. **画面**：逐帧亮度突变 → 每一次开花（看到的时刻）
2. **声音**：从配乐和人群欢呼中检出每一声爆炸（听到的时刻），并把山谷/楼群回声抑制掉、不算成另一发
3. **测距**：同一发的（听到 − 看到）时间差 × 当时气温下的声速 = 观众到爆点距离
4. **节拍对照**：开花时刻与配乐节拍对比，算出每发提前/落后多少毫秒
5. **点火修正**：按偏差反推编排表点火时间该往前（或往后）挪多少

## 四个页面

| 页面 | 功能 |
| --- | --- |
| 录像导入 | 视频文件解码（音轨→PCM、画面→逐帧亮度）、场地/气温/飞行时间参数、一键生成自带真实值的合成测试录像 |
| 声光事件 | 闪光/爆炸/节拍时间轴、逐发光声配对与测距、回声抑制明细 |
| 节拍对照 | 每发开花相对最近节拍的提前/落后毫秒数、准点统计、偏差分布直方图 |
| 点火修正 | 编排表 CSV 导入/编辑、修正量计算、修正后 CSV 导出 |

## 技术架构

- **语言**：TypeScript 严格模式；声音处理走 **Web Audio API**
- **AudioWorklet**：爆炸声检测（`explosion-worklet.ts`）与节拍跟踪（`beat-worklet.ts`）各一个 Worklet 节点，实时路径在音频线程逐渲染块推进
- **同构算法**：Worklet 与离线/Node 自检共用 `src/core` 下的同一套检测类（`ExplosionDetectorStream`、`BeatTrackerStream`），保证自检覆盖的就是上线代码
- **无第三方运行时依赖**：FFT、自适应噪声底、频谱平坦度、自相关 BPM、回声指纹比对全部手写

### 核心算法要点

- **爆炸声 vs 音乐鼓点**：低频 thump 起振 + 宽带爆轰（1–6kHz）双判据，事件级高频能量比噪声底高一个数量级、频谱平坦度高、持续 ≥100ms，鼓点在这三项上都不满足
- **回声抑制**：场地相关时间窗内，频谱指纹余弦相似度 + 能量衰减比 + 回声链溯源；两排楼之间来回反射的三次回声归并到同一发主爆
- **光声配对**：枚举物理可行配对，取延迟直方图众数为整场基准（同机位各发距离一致），一对一贪心剔除混响离群候选
- **声速校正**：`c(T) = 331.3 + 0.606·T`（℃），-10℃~30℃ 全区间按当时气温换算
- **节拍跟踪**：包络 onset + 自相关估周期 + 滑动节拍网格（锚点吸附、杂散剔除、漏拍外推补齐、拍时平滑）

## 目录结构

```
src/
  core/            纯 TS、无 DOM 依赖的算法（Worklet/浏览器/Node 共用）
    dsp.ts           FFT、窗函数、包络、相似度
    physics.ts       声速、光声测距
    synth.ts         合成测试录像生成（三场地回声+配乐+欢呼）
    explosion-detector.ts  爆炸声检测流 + 回声抑制
    beat-tracker.ts        节拍跟踪流
    flash-detector.ts      画面闪光检测
    analysis.ts      端到端流水线
    types.ts         类型与场地参数
  worklets/        AudioWorklet 入口（esbuild 单独打包到 public/worklets）
  app/             应用层：store、视频解码、Worklet 引擎、四个页面
scripts/
  run-selftest.ts        27 组场地×气温×距离的指标自检
  verify-requirements.ts 需求条款专项验证
```

## 使用

```bash
npm install
npm run dev          # 开发服务器（会先构建 worklet）
npm run build        # 类型检查 + 生产构建
npm run selftest     # 合成数据指标自检（27 组用例）
npm run verify       # 需求条款专项验证
```

无真实录像时，在「录像导入」页用「合成测试录像」即可生成含配乐、人群欢呼、礼花爆炸、场地回声且自带真实值的片段，直接核查并对照。

## 验收指标（合成测试录像实测）

| 指标 | 门槛 | 实测 |
| --- | --- | --- |
| 爆炸声检出率 | ≥ 95% | 95.8% |
| 回声误检为另一发 | ≤ 2% | 0% |
| 光声测距误差 | ≤ 距离的 5% | 最差 1.57% |
| 三次回声只算一发 | 必须 | 通过（20 发主爆 + 40 次回声 → 20 个主事件） |
| -10~30℃ 声速校正 | 全区间 | 最差 0.24% |
| 4 分钟演出核查耗时 | ≤ 30s | ≈ 9s |

> 节拍跟踪 F1（70ms 容差）实测约 87%，为内部观测指标；山谷长混响下原始 onset 召回是主要瓶颈，网格正则化已把杂散与漏拍大幅修正。
